# 법령 MCP 실무 프롬프트 40선 — 1인기업·강사·프리랜서·소상공인 편

[법령 MCP 실무 프롬프트 20선](https://kjs369369.github.io/law-mcp-prompts20/)(시리즈 1, 기업 실무자용)의 **시리즈 2**입니다.
법무팀이 없는 사람이 자기 사업에서 실제로 부딪히는 상황을 기준으로 분야와 개수를 늘렸습니다.

## 구성

| 분야 | 수 | 다루는 상황 |
|---|---|---|
| ① 계약·수주 | 5 | 독소조항 점검 · 대금 지급기한 · 저작권 귀속 · 중도 취소 · 표준계약서 대조 |
| ② 세금·4대보험 | 5 | 3.3% 원천징수 · 부가세 과세/면세 · 간이과세 · 필요경비 · 4대보험 |
| ③ 창업·인허가 | 5 | 사업자등록 · 통신판매업 신고 · 업종별 인허가 · 자택 사업장 · 법인 전환 |
| ④ 저작권·콘텐츠 | 5 | 인용 범위 · 폰트/이미지 라이선스 · AI 생성물 · 후기·사진 활용 · 브랜드명 |
| ⑤ 온라인판매·광고 | 5 | 표시의무 · 환불/청약철회 · 광고 문구 · 대가성 표시 · 구독 해지 |
| ⑥ 개인정보·발송 | 5 | 명단 관리 · 광고성 정보 동의 · 발송 시간 제한 · 처리방침 · 위탁/제3자 제공 |
| ⑦ 매장·알바 | 5 | 갱신요구권 · 권리금 · 임대료 인상 한도 · 알바 근로계약 · 5인 미만 경계 |
| ⑧ 분쟁·회수 | 5 | 내용증명 · 지급명령/소액사건 · 소멸시효 · 추심 금지행위 · 폐업 절차 |

분야마다 **"이런 상황에 씁니다"** 실무 사례 박스가 하나씩 붙어 있어, 어떤 프롬프트를 어떤 순서로 쓰는지 안내합니다.
검색·분야 필터·원클릭 복사를 지원합니다.

## 선행 조건

프롬프트는 **법령 MCP가 연결된 상태**에서 작동합니다. 연결 전에는 AI가 기억에 의존해 답하므로
조문 번호나 금액 기준이 틀릴 수 있습니다.

- 설치 방법: https://koica-law-mcp.vercel.app/
- OC 키 발급(무료·즉시): https://open.law.go.kr

> 조회 전용 도구이며 법률자문이 아닙니다. 계약·분쟁·세무처럼 돈과 책임이 걸린 판단은
> 반드시 변호사·세무사 등 전문가 확인을 거치십시오.

## 작성 원칙

- 프롬프트 본문에 **조문 번호를 박아 두지 않습니다.** 개정으로 번호가 바뀌기 때문에,
  법령명과 조문의 성격(예: "청약철회에 관한 조문")만 지정하고 번호는 AI가 조회하게 합니다.
- 본문에 등장하는 **법령명은 국가법령정보 API로 정식 제명을 검증**했습니다.
  (예: `표시ㆍ광고의 공정화에 관한 법률` — 가운뎃점은 `ㆍ`)
- 세율·보증금 한도·인상률·소액사건 금액처럼 변동이 잦은 값은
  프롬프트 안에서 **조문 원문 인용을 강제**합니다.
